The F&B ERP System project structure and documentation has been successfully set up for the 300-outlet F&B chain microservices architecture.

- Implementation guides
- Database schema definitions

- **Master Data Layer**: Central reference data in PostgreSQL
- **Operational Data Layer**: Transactional data in PostgreSQL
- **Reporting Data Layer**: Analytics and business intelligence in Snowflake
